# LikeFolder — Android (MVP 0.1.0)

Самостоятельное Android-приложение для синхронизации «Мне нравится» из Яндекс Музыки и выгрузки **доступных обычных MP3** в общую папку телефона (по умолчанию `Music/YandexLiked/`). Файлы не являются кэшем LikeFolder: это отдельные `.mp3`, доступные через файловый менеджер и любой совместимый плеер.

**Статус:** исходный код подготовлен, синтаксически проверен. На реальном Android и с рабочим аккаунтом Яндекса в рамках этого окружения не тестировался. В среде подготовки отсутствовали Android SDK/Gradle, поэтому готовый APK не приложен — проект содержит GitHub Actions для сборки APK.

## Возможности

- Вход в Яндекс ID через Device OAuth (код в браузере Яндекса, без ввода пароля в приложении); запасной вариант — ввод своего OAuth-токена.
- Снимок существующих лайков при первом входе: автоматическая синхронизация после этого скачивает **только новые** понравившиеся треки.
- Отдельная кнопка **«Выгрузить все понравившиеся MP3»** для первоначальной загрузки всей медиатеки.
- Периодическая проверка через WorkManager (не чаще 15 минут, может выполняться с задержкой).
- Опциональный «быстрый режим» — проверка раз в ~2 минуты с постоянным Android-уведомлением и ограничениями Android 15+.
- Защита от повторных скачиваний по ID трека.
- Сохранение через MediaStore в `Music/<имя папки>/`; не нужны root и доступ ко всему файловому хранилищу.
- Названия файлов `Исполнитель - Название.mp3`; при коллизиях добавляется ID. ID3v2.3 с названием, исполнителем и альбомом добавляются, если поток не содержит ID3.
- Опция скачивания только по Wi-Fi (включена по умолчанию для автоматической загрузки).
- Токены хранятся в зашифрованном виде с ключом Android Keystore.
- Выход из аккаунта не удаляет сохранённые MP3.

## Сборка через GitHub Actions (без установки Android Studio)

1. Создайте **приватный** GitHub-репозиторий, например `likefolder-android`.
2. Загрузите в него **содержимое** этой папки, включая скрытую `.github/workflows/android.yml` (не архив как один файл).
3. В разделе **Actions** запустите **Build Android APK** → **Run workflow**. На коммит в `main`/`master` сборка тоже запускается.
4. После успешного выполнения откройте run → **Artifacts** → `LikeFolder-debug-apk`.
5. Скачайте zip артефакта, распакуйте и установите `app-debug.apk` на свой Android. В системных настройках может потребоваться разрешить установку из этого источника.

Тот же вариант локально в Android Studio: откройте корень проекта, дайте Gradle загрузить зависимости, выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Требуются JDK 17, Android SDK Platform 35, Gradle 8.9 и подключение к Maven/Google.

## Использование

1. Установите APK и запустите LikeFolder на **Android 10+**.
2. Нажмите «Получить код входа», откройте страницу Яндекса, введите отображённый код, разрешите доступ. Пароль Яндекса в приложение не передаётся.
3. Приложение запомнит текущие лайки — ранее понравившиеся треки **не** скачаются автоматически при первом входе.
4. Чтобы получить уже отмеченные песни, нажмите «Выгрузить все понравившиеся MP3». Для новых лайков далее работает автосинхронизация.
5. Файлы появятся в `Внутренняя память / Music / YandexLiked /`. При переименовании папки существующие файлы автоматически не переносятся; история уже загруженных ID сохраняется.
6. Для максимально быстрого обнаружения новых лайков включите «Быстрый режим», пока слушаете музыку. Он показывает постоянное уведомление, потребляет батарею и может быть ограничен ОС.

## Ограничения и безопасность

- Это **неофициальный** клиент и не является продуктом или партнёром Яндекса.
- Используется `api.music.yandex.net`, методы `/users/{uid}/likes/tracks`, `/tracks`, `/tracks/{id}/download-info`. Для обычного нешифрованного MP3 используется legacy CDN-ссылка. API может измениться или перестать предоставлять MP3.
- **Нет обхода DRM, извлечения ключей, расшифровки официального кэша или перехвата приложения Яндекс Музыки.** Если API возвращает только защищённый формат, трек не будет скачан. Не гарантируется доступ ко всей медиатеке.
- В соответствии с документацией Яндекса официальное офлайн-хранилище зашифровано. Сохранение самостоятельных файлов может не соответствовать условиям использования музыкального сервиса и затрагивать права правообладателей. Используйте только в случаях, когда у вас есть соответствующее право.
- Для примера OAuth использованы общедоступные значения `client_id` и `client_secret` неофициальных библиотек. Они не являются вашей личной тайной, но их использование может быть отключено Яндексом. Для коммерческого или публичного распространения нужен собственный согласованный механизм авторизации.
- Токен никогда не передаётся сторонним серверам: запросы с `Authorization` ограничены `api.music.yandex.net`. Ссылка на аудио CDN загружается без OAuth-токена.
- Приложение **не** получает доступ к паролю Яндекса, не собирает аналитику и не использует сторонний сервер.
- Тестировать следует сначала на небольшом наборе треков: API недокументирован, могут встречаться ошибки метаданных, URL и медиасканера. Если 5 первых MP3 подряд не скачались, выгрузка останавливается с сообщением о причине.
- Debug APK подписан стандартным отладочным ключом GitHub Actions, не предназначен для официальной публикации. При переходе на production нужна своя подпись и release-сборка.

## Структура

- `app/src/main/java/com/likefolder/app/MainActivity.java` — UI и OAuth Device Flow.
- `YandexApi.java` — синхронизация любимых треков, сведения о MP3 и OAuth refresh.
- `Mp3Writer.java` — проверка формата, ID3 и запись через MediaStore.
- `SyncEngine.java` — правила «новые/все», дедупликация, очередь.
- `SyncWorker.java` — периодическая фоновая синхронизация.
- `SyncService.java` — ручные загрузки, ускоренная синхронизация, уведомления.
- `Store.java` — настройки, состояние, зашифрованные токены.
- `.github/workflows/android.yml` — готовая CI-сборка Android APK.

## Технические параметры

`Java 17 · Android Gradle Plugin 8.7.3 · WorkManager 2.10.0 · compileSdk 35 · targetSdk 35 · minSdk 29`

## Права на использование

Код приложения предоставлен для личного экспериментального использования, без гарантий работы с недокументированным API и без гарантий прав на скачиваемые фонограммы. При публикации проверьте условия использования Яндекс Музыки и права на используемые материалы.
