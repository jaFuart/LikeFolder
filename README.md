# ❤️ LikeFolder

**Любимые треки — в твоей папке MP3.**

Сохраняй понравившуюся музыку из Яндекс Музыки на телефон и слушай её в удобном плеере.

### [↓ Скачать APK](https://github.com/jaFuart/LikeFolder/releases/latest/download/LikeFolder.apk)

Для **Android 10 и новее**.

## Что умеет

- **Следит за новыми лайками** и автоматически сохраняет треки в фоне.
- **Скачивает выбранное** — несколько песен или всю коллекцию «Мне нравится».
- **Находит нужное** по названию трека и исполнителю.
- **Наводит порядок**: сортировка по дате лайка, названию и исполнителю, фильтры скачанных и нескачанных треков.
- **Останавливает загрузку** по нажатию — уже сохранённые MP3 остаются на телефоне.
- **Сохраняет в твою папку**. По умолчанию это `Music/YandexLiked/`; имя можно изменить в приложении.

## Начать просто

1. **Установи APK** и открой LikeFolder.
2. **Подключи Яндекс ID**: получи код, нажми на него для копирования и подтверди вход на странице Яндекса.
3. **Открой медиатеку**, найди и отметь нужные треки, затем нажми «Скачать выбранные». Для всей коллекции есть «Выгрузить все понравившиеся MP3».

После первого входа автоматическая загрузка следит за новыми лайками. Уже понравившиеся песни выбирай в медиатеке.

---

LikeFolder — неофициальное приложение, не связанное с Яндексом. Скачать можно только те треки, для которых сервис предоставляет MP3.
