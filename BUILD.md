# Краткая инструкция

**1.** Загрузите содержимое этого проекта в приватный репозиторий GitHub (включая скрытую папку `.github`).

**2.** Откройте Actions → Build Android APK → Run workflow.

**3.** После успешной сборки скачайте Artifacts → `LikeFolder-debug-apk`, достаньте `app-debug.apk` и установите на Android 10+.

**4.** В приложении подключите Яндекс ID → нажмите «Выгрузить все понравившиеся MP3» или оставьте автоматическую синхронизацию для новых лайков.

**Примечание:** исходники не были собраны в APK и не прошли испытания с реальным аккаунтом. Это экспериментальный MVP на неофициальном API. Если поток MP3 не предлагается или защищён, приложение его не обходит.
